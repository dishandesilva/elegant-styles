# Elegant Styles - Frontend E-Commerce Website

Elegant Styles is a frontend-only e-commerce web project built as a university assignment. The project focuses on modern UI design, multi-page navigation, and common online shopping flows using static data.

## About The Project

This project demonstrates how a complete shopping website experience can be built using core web technologies without a backend service.

It includes:
- A landing page with promotional sections and carousels
- Product browsing and quick product view interactions
- Cart and wishlist interfaces
- User account-related pages (orders, profile settings, payments, reviews, returns)
- Support pages such as contact, help center, and message center
- Seller and admin-facing entry pages

## Key Features

- Multi-page e-commerce frontend architecture
- Responsive design for desktop and mobile screens
- Interactive UI elements (loaders, sliders, popups, hover effects)
- Product filter and sort interface on shop page
- Frontend authentication screens (Sign In / Sign Up UI)
- Modular CSS and JavaScript files for maintainability

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap
- Bootstrap Icons

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project folder

```bash
cd "Project Elegant Styles"
```

### 3. Run the project

Since this is a static frontend project, you can run it in any of the following ways:

- Open `index.html` directly in your browser, or
- Use VS Code Live Server extension, or
- Place the project inside your local server directory (for example XAMPP `htdocs`) and open it via localhost

## Limitations

- This project is frontend-only
- No backend/database integration
- No real authentication, payment gateway, or order processing
- Data shown is static/demo data
